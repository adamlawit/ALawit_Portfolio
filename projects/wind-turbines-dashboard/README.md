# U.S. Wind Turbine Dashboard/Analysis

### Author: Adam Lawit  

---

## Project Overview

This project analyzes the distribution and characteristics of wind turbines across the United States using interactive Tableau dashboards and geospatial visualization.

The goal is to better understand regional patterns in wind energy deployment and infrastructure.

---

## Objectives

- Map wind turbine locations across the U.S.  
- Analyze capacity and distribution by state  
- Identify regional trends in wind energy development  
- Build an interactive dashboard for exploration

## Key Insights

- California was the earliest to install
- Texas and the Midwest dominate U.S. wind capacity  
- Wind turbines are concentrated in high-wind corridors
